mirage.photo.photometry.process_subframes(dates: ndarray[datetime], data: ndarray, file_names: list[str] = None, stride: int = 1, crop_half_width: int = 15, signal_mask_threshold: float = 2.5, background_mask_threshold: float = 2.0, background_reduction_factor: int = 8, saturation_limit_adu: int = 4095, sub_crop_dist_limit: float = 3.0, min_star_contour_length: int = 30, centroid_mode: Literal['max', 'weighted'] = 'max', skip_indices: list = None, plot_mask: bool = False, plot_full: bool = False, plot_crop: bool = False) → DataFrame#

Extracts calibrated object fluxes from a sequence of images.

Parameters:

  • dates (np.ndarray[datetime.datetime]) – Dates corresponding to the image sequence [UTC]

  • data (np.ndarray [n,height,width]) – Image stack

  • file_names (list[str], optional) – Optional image names used in diagnostic messages, defaults to None

  • stride (int, optional) – Stride through the image stack, defaults to 1

  • crop_half_width (int, optional) – Half-width of the crop around the centroid [pix], defaults to 15

  • signal_mask_threshold (float, optional) – Radius of the source signal aperture [pix], defaults to 2.5

  • background_mask_threshold (float, optional) – Sigma-clipping threshold for background estimation, defaults to 2.0

  • background_reduction_factor (int, optional) – Downsampling factor used for background estimation, defaults to 8

  • saturation_limit_adu (int, optional) – Pixel value treated as saturation [ADU], defaults to 4095

  • sub_crop_dist_limit (float, optional) – Maximum allowed centroid offset from the subframe center [pix], defaults to 3.0

  • min_star_contour_length (int, optional) – Minimum star contour length parameter, retained for API compatibility and currently unused, defaults to 30

  • centroid_mode (Literal['max', 'weighted'], optional) – Centroid method, either 'max' or 'weighted', defaults to 'max'

  • skip_indices (list, optional) – Frame indices to skip, defaults to None

  • plot_mask (bool, optional) – Whether to plot the source signal mask, defaults to False

  • plot_full (bool, optional) – Whether to plot the full-frame contour diagnostics, defaults to False

  • plot_crop (bool, optional) – Whether to plot the cropped subframe, defaults to False

Returns:

Table with dates, fluxes [ADU], background standard deviations, and object pixel counts

Return type:

polars.DataFrame
